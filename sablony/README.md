# Šablony pro data repozitář

Založ si soukromý repozitář `nutrition-data` s touto strukturou:

```
nutrition-data/
  profil.md          # ze sablony profil.md
  produkty.yaml      # ze sablony produkty.yaml
  roadmap.md         # otevřené body a nápady
  restaurants.md     # ze sablony restaurants.md, jen kdo chodí na obědy do restaurace
  mereni/README.md   # ze sablony mereni.md
  jidelnicky/        # jeden soubor na týden ze sablony jidelnicek.md
```

Oba repozitáře klonuj vedle sebe, aby Claude našel data jako `../nutrition-data`.
